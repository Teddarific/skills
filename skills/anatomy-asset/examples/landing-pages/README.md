# Example landing pages

Two landing pages built around the example brand sets, as React + Tailwind (v4) components. Every illustration is an asset from `examples/`, loaded as a plain `<img>` from the repo through jsDelivr.

- `aether/`: Aether, electric aviation. Dark. Uses `aero-vertiport` (hero, with the headline in its safe zone), `aero-spots`, `aero-hangar` and `aero-satellite`.
- `halden/`: Halden, clean energy. Light. Uses `energy-turbine` (hero), `energy-spots`, `energy-solar-farm` and `energy-home`.

Each folder has an `App.tsx` exporting `App`, and an `index.css` with the fonts. Both are also live as designs in Magic Patterns.
