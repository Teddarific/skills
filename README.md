# Teddarific / skills

Agent skills for Claude Code, OpenCode, Codex and Antigravity. Each one is a folder under [`skills/`](skills); install any of them with:

```sh
npx skills add Teddarific/skills --skill <name> -g
```

## Skills

| Skill | Description |
|---|---|
| [`anatomy-asset`](skills/anatomy-asset) | Crafted isometric SVG illustrations for landing pages and product sites. A fork of [Anatomy](https://github.com/wheresryan22/anatomy). |
