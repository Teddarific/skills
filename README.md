# Teddarific / skills

Agent skills for Claude Code, OpenCode, Codex, Antigravity and Grok Bot. Each one is a folder under [`skills/`](skills); install any of them with:

```sh
npx skills add Teddarific/skills --skill <name> -g
```

## Skills

| Skill | Description |
|---|---|
| [`anatomy-asset`](skills/anatomy-asset) | Crafted isometric SVG illustrations for landing pages and product sites. A fork of [Anatomy](https://github.com/wheresryan22/anatomy). |
| [`what-if`](skills/what-if) | A daily drop of about 10 short, code-rendered "What if…" concept films built on your real product and posted to Slack. Tuned for Grok Bot, with a paste-in setup prompt. |
